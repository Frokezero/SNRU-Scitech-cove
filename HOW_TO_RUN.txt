======================================================================
     คู่มือการติดตั้งและรันระบบบนเครื่องใหม่ (University Activity Calendar)
======================================================================

เนื่องจากไฟล์ระบบที่สำคัญ เช่น ฐานข้อมูล (database.sqlite) และโฟลเดอร์รันไทม์ (.venv) 
ถูกซ่อนไม่ให้อัปโหลดขึ้น GitHub เพื่อความปลอดภัยของข้อมูลและขนาดโปรเจกต์ 
เมื่อดาวน์โหลดโค้ดลงเครื่องใหม่แล้ว ต้องทำตามขั้นตอนต่อไปนี้เพื่อรันระบบ:

----------------------------------------------------------------------
ขั้นตอนที่ 1: ติดตั้ง Python และตั้งค่า Environment
----------------------------------------------------------------------
1. ตรวจสอบว่าเครื่องมี Python ติดตั้งอยู่แล้ว (แนะนำเวอร์ชัน 3.10 ขึ้นไป)
2. เปิดโปรแกรม Command Prompt (cmd) หรือ PowerShell 
3. พิมพ์คำสั่งเพื่อเปิดโฟลเดอร์โปรเจกต์ (เช่น cd /d "D:\โฟลเดอร์ใหม่ (6)\1122220")
4. สร้างสภาพแวดล้อมจำลอง (Virtual Environment):
   python -m venv .venv

5. เปิดใช้งานสภาพแวดล้อมจำลอง (Activate):
   * หากใช้ PowerShell:
     .venv\Scripts\Activate.ps1
   * หากใช้ Command Prompt (cmd):
     .venv\Scripts\activate.bat

6. ติดตั้งไลบรารีทั้งหมดในเครื่องใหม่:
   pip install -r requirements.txt

----------------------------------------------------------------------
ขั้นตอนที่ 2: ตั้งค่าไฟล์ระบบ (.env)
----------------------------------------------------------------------
1. คัดลอกไฟล์ ".env.example" ในโฟลเดอร์นี้ แล้ววางและเปลี่ยนชื่อเป็น ".env"
2. เปิดไฟล์ ".env" ด้วย Notepad หรือ Text Editor
3. แก้ไขข้อมูลตัวแปรตามความหมายของไฟล์ .env.example ดังนี้:

   - SECRET_KEY      : รหัสผ่านความปลอดภัยสูงของระบบเซสชัน (สามารถสุ่มพิมพ์อะไรก็ได้ยาวๆ เช่น my-super-key-1234)
   - SENDER_EMAIL  : อีเมลของระบบที่จะใช้ส่งข้อความแจ้งเตือนหรือรหัสผ่านให้ผู้ใช้ (เช่น user@gmail.com)
   - SENDER_PASSWORD: App Password ของอีเมลดังกล่าว (กรณีใช้ Gmail ต้องเข้าไปสร้าง App Password ในบัญชี Google ก่อน ไม่ใช่รหัสผ่านอีเมลปกติ)
   - SMTP_SERVER    : ที่อยู่เซิร์ฟเวอร์ของระบบส่งอีเมล (เช่น smtp.gmail.com)
   - SMTP_PORT      : พอร์ตการเชื่อมต่ออีเมล (ปกติคือ 587)


----------------------------------------------------------------------
ขั้นตอนที่ 3: สร้างฐานข้อมูลและนำเข้าข้อมูลตั้งต้น
----------------------------------------------------------------------
ให้พิมพ์คำสั่งต่อไปนี้ทีละคำสั่ง (ในขณะที่ .venv ยังทำงานอยู่):

1. สร้างข้อมูลจำลองเริ่มต้น:
   python seed_full_data.py

2. สร้างบัญชีผู้ใช้งานแอดมินสาขาต่างๆ:
   python init_majors.py

3. นำข้อมูลเข้าระบบฐานข้อมูล SQLite (ระบบจะสร้างไฟล์ database.sqlite ขึ้นมาอัตโนมัติ):
   python migrate_to_sqlite.py

----------------------------------------------------------------------
ขั้นตอนที่ 4: รันเพื่อเปิดใช้งานเว็บไซต์
----------------------------------------------------------------------
เมื่อทำทุกขั้นตอนสำเร็จแล้ว สามารถเริ่มรันเว็บไซต์ได้โดย:

รันคำสั่ง:
python app.py

หรือดับเบิลคลิกเปิดไฟล์ "run_app.bat" เพื่อเริ่มระบบได้ทันที
เข้าใช้งานผ่านเบราว์เซอร์ที่ลิงก์: http://localhost:5000 หรือตามพอร์ตที่ระบบแจ้งไว้
